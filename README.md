Snort 2.9.20 Network Intrusion Detection System (IDS)

A practical Snort IDS configuration for monitoring network traffic and detecting suspicious activities such as ICMP ping attacks, ICMP flooding, large ICMP packets, and TCP SYN port scans. The project includes custom Snort rules, network configuration, promiscuous mode setup, and testing procedures. This setup can be integrated with Wazuh to provide network and endpoint security monitoring for an Active Directory intrusion detection environment.

Key Features:

🔍 Snort 2.9.20 IDS configuration
🌐 Network traffic monitoring using ens33
📡 Promiscuous mode configuration
🏠 Protected network configuration with HOME_NET
🛡️ ICMP ping detection
🚨 ICMP flood/high-rate detection
📦 Large ICMP packet detection
🔎 TCP SYN port-scan detection
📊 Custom local Snort rules
🔗 Wazuh integration for centralized security monitoring
🏢 Designed for Active Directory security monitoring
